# Envio de relatórios Globus

Coloque relatórios gerenciais do Globus em `entrada/` usando a interface do GitHub. O envio dispara validação automática e, se os dados forem válidos, uma proposta (pull request) para atualizar o dashboard.

O repositório é público: arquivos TXT enviados aqui ficam acessíveis publicamente. A análise do dashboard usa dados até 29/10/2026, inclusive. Consulte `ATUALIZAR_RELATORIOS_GLOBUS.md` para o fluxo e as regras.
